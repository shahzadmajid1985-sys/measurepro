How to use

  1. Capture a photo with a real ruler or known-length object visible. The live camera shows a dotted 12-inch positioning guide; line it up with a real 12-inch ruler if available.
  2. Enter the real length of the visible reference (for example, 12 inches or 1 foot) and choose its unit (cm, in, ft, m, or mm). The screen guide alone cannot calibrate the photo.
  3. In Line mode, draw a line from one end of the reference to the other. This sets the scale.
  4. Draw other lines to measure lengths. In 4-point shape mode, click the first corner, then move the pointer to preview a dotted guide with live length and angle; drag/release to place each next corner.
  5. Select a measurement to view its result. Drag a completed line or shape to move it. Zoom in/out for fine placement.
  6. Use Undo/Redo to reverse changes, and Save project/Open project to keep working later on the same photo.
  7. Use Export JPEG or Export PNG for a high-resolution image with transparent measurement labels. Export PDF report creates a multi-page report with project name, date, measured photo and a separate measurement schedule; choose “Save as PDF”. Save project keeps an editable .measurepro copy for later. In browsers that support Save As, choose the folder and filename; otherwise it downloads using the project name. To reopen, open MeasurePro first and click Open project (double-clicking a .measurepro data file may show raw data in Chrome instead of loading it into the app).
  8. Use Clear measurements to remove measured lines and shapes while keeping the reference.

Accuracy note: this calculates measurements in the image plane. Perspective, camera angle, lens distortion, and objects at different depths can cause errors. It is not a substitute for a physical measuring tool.
